CLIMARO

Real-Time Weather Intelligence & Forecast Dashboard

Architecture Report
✅ 100% Free & Keyless Architecture: This project requires NO API KEY. All weather data is retrieved in real-time directly from Open-Meteo's open-access meteorological endpoints.

Library Version Usage

Google Fonts (Inter) Weights 300–800 Modern typography for clean data readouts and digital clocks.

3. External APIs & Data Sources (No API Key Needed)

API Service Type Functionality
Open-Meteo Forecast API Weather Endpoint Real-time temperature, feels-like, humidity, wind, pressure, UV index, 24h hourly, and 7-day outlook.
Open-Meteo Geocoding API Search Endpoint Worldwide city search with instant matching suggestions and coordinates.
OpenStreetMap Nominatim Reverse Geocoding Resolves browser geolocation coordinates into human-readable city names.
HTML5 Geolocation API Browser API Captures current device position when user clicks "Current Location".
localStorage API Browser Storage Persists saved favorites, recent searches, °C/°F units, and light/dark theme.
